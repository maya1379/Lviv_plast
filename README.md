# Voting App (Azure + FastAPI)

Система експрес-голосування для одночасної участі до 400+ користувачів.

## Локальний запуск:
1. `python3 -m venv venv`
2. `source venv/bin/activate`
3. `pip install -r requirements.txt`
4. Заповніть ваші ключі в `.env`
5. `python3 main.py`

- Сторінка голосування: http://localhost:8000/
- Панель адміністратора: http://localhost:8000/admin
